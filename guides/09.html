1. 교수설계가이드 개요

2027학년도 1-2 데이터베이스의 교수설계가이드 공동 작성 및 교과 간 연계 검토

2. 교과목 개요

관계형 DB 설계·SQL·CRUD·정규화 / 학점 3 / 담당 예정 미정

3. AI·DX 기반 교육의 이해

AI·DX 보조 도구는 학습 과정에서 활용하되 학습자의 직접 구현·설명·검증을 필수로 한다.

4. AI·DX 교과목 수업 설계

개념 학습 → 실습 수행 → 오류 검증 → 피드백 → 성찰 기록의 수업 흐름을 운영한다.

5. AI·DX 활용 학습 환경

데이터베이스 관련 소프트웨어·장비 · GitHub·대학 LMS
